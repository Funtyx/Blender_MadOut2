# MadOut2 Tools для Blender

Все инструменты MadOut2 на одной вкладке **MadOut2** в боковой панели 3D View (клавиша `N`). Нужен Blender 4.2 или новее.

## Установка

1. Откройте **Edit → Preferences → Get Extensions**. Если Blender попросит, нажмите **Allow Online Access**.
2. Справа вверху нажмите **Repositories** → **+** → **Add Remote Repository**.
3. В поле **URL** вставьте:
   ```
   https://raw.githubusercontent.com/Funtyx/Blender_MadOut2/main/repo/index.json
   ```
   Включите **Authentication** и в поле **Access Token** вставьте токен, который вам дали.
4. Найдите в списке **MadOut2 Tools** и нажмите **Install**.

Обновления Blender проверяет сам: когда выйдет новая версия, рядом с аддоном появится кнопка **Update**.

## MadOut2 V2

Отдельный аддон из того же репозитория (нужен Blender 5.1+): найдите в списке **MadOut2 V2** и нажмите **Install**. Вкладка **MadOut2 V2** в боковой панели:

- **Strip Resample** — выделите в Edit Mode линии вдоль полосы (края дороги, бордюров) и запустите: поперечные рёбра встанут равномерно по гладкой кривой, с учётом высот. Количество сегментов или шаг, сглаживание и сохранение острых углов — в панели F9. Соседняя геометрия остаётся сваренной, UV и цвета вершин переносятся.
- **Ground Fill** — выделите две цепочки рёбер и залейте между ними сетку: число рядов, подъём или прогиб (Bulge), форма профиля, сдвиг вершины, затухание у концов.
- **Big Edge Length** — крупные подписи длин рёбер: размер шрифта, цвет, подложка. Настройки на вкладке и в Overlays → Measurement.

## Выпуск новой версии

1. Поднимите `version` в `addons/<аддон>/blender_manifest.toml`.
2. Выполните `python3 publish.py`.
3. Закоммитьте и запушьте изменения вместе с папкой `repo/`.
